# NordFlow runtime tools

Generated by `python3 -m phase2.gen_tool_docs` from the query-layer signatures and docstrings. Every tool is read-only. `?` marks an optional parameter. The example arguments are the ones the test suite runs against the fixture data.

## Metadata

### `meta_describe_sources`

The four source systems: tables, row counts, date coverage and field descriptions.

No parameters.

Example: `meta_describe_sources()`

### `meta_get_semantics`

Definitions of fields, dates, currencies, markets (incl. fallback rules), product categories, CRM
stages, metric definitions and known data-quality caveats. topic: systems | currencies | dates |
markets | product_categories | crm_stages | metrics | data_quality (omit for all).

| parameter | type | default |
|---|---|---|
| `topic` | `str?` | `None` |

Example: `meta_get_semantics(topic='markets')`

## ERP / Finance

### `erp_customer_revenue`

Revenue and gross profit per ERP customer, with each customer's first and last invoice date in the
whole export. With compare_to, customers active in either period are included with change columns
(sort_by='revenue_dkk_change' ascending lists the largest decreases). first_invoice_from/to filter
customers by when they were first invoiced (e.g. to separate new from existing customers).

| parameter | type | default |
|---|---|---|
| `period` | `str` | required |
| `compare_to` | `str?` | `None` |
| `market` | `str?` | `None` |
| `category` | `str?` | `None` |
| `first_invoice_from` | `str?` | `None` |
| `first_invoice_to` | `str?` | `None` |
| `min_revenue_dkk` | `float?` | `None` |
| `sort_by` | `str?` | `'revenue_dkk'` |
| `ascending` | `bool` | `False` |
| `limit` | `int` | `50` |

Example: `erp_customer_revenue(period='2026-H1', compare_to='2025-H1', market='DE', sort_by='revenue_dkk_change', ascending=True, limit=5)`
